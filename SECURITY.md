# Security

Usage Coach runs only inside your own Claude Code. It makes no network requests and collects nothing (see `PRIVACY.md`).

## Reporting a problem

If you find a security issue, please report it privately: on GitHub, open the **Security** tab of this repository and choose **Report a vulnerability**. Please do not open a public issue for it.

Only the latest version is supported. Fixes ship as a new version of the plugin.
